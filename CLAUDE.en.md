## Key decisions at a glance

- Stack: NestJS + **TypeORM** + TypeScript (strict), **Rich Domain 4-Layer** (interface/application/domain/infrastructure)
- Where rules live: **entity** = domain rules (if·invariants) / **command service** = wiring (load·save·transaction) / **infra** = external libraries (TypeORM, etc.)
- Ports: **interface + InjectionToken**, adapter implementations in infra
- CQRS: **folder split YES / CommandBus deferred** (Query never uses the Repository — a separate read path)
- Cross-domain: **another domain = adapter** (all reads·writes) / atomic cross-domain writes use a **synchronous transaction** (`@Transactional`) / side effects use events (EventEmitter)
- Cycles: **prevented by design** (owner = first URL segment, one direction) — forwardRef forbidden
- Errors: the entity throws a domain exception (knows no HTTP) → the global filter converts it to the envelope. Code format `<DOMAIN>_<REASON>`
- Response: `{ code, message, result }` envelope
- ID: generated by the domain at `create()` time (`common/generate-id.ts`, UUID v4 by default)
- Auth: global `JwtAuthGuard` + `@Public()` + `@CurrentUser()` (verification skeleton — issuance is left to the project)
- Naming: domain/application/infra role files use **hyphens** (`-module.ts`, etc.); only Nest primitives use dots (`.guard.ts`·`.entity.ts`, etc.)
- Pagination: offset (admin·search) + cursor (feed·infinite scroll) in parallel
- Git: main + feature PR → **Squash merge**. Commits `type(scope): summary`. **1 PR = 1 logical change** (keep it small)
- Boundary enforcement: the boundaries rules in `eslint.config.mjs` fail the build on layer/domain violations
